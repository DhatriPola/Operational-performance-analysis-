# Operational Performance Dashboard in Power BI

### Track your team’s workload and performance at a glance!

## Project Overview

This interactive Power BI dashboard provides a clear view of team workload and operational performance. It helps leaders monitor request activity, evaluate SLA performance and identify delays that may affect day-to-day operations.

The dashboard brings key operational metrics together in one place so teams can balance assignments, improve accountability and keep work moving efficiently.

## Business Problem

Operational teams handle a large volume of requests with different priorities, deadlines and processing requirements. Without centralized reporting, it can be difficult to understand:

- How work is distributed across the team
- Which requests are approaching or exceeding SLA targets
- Where delays and processing bottlenecks occur
- Which areas require additional support or reassignment
- How team performance changes over time

## Dashboard Highlights

- Tracks incoming, open and completed requests
- Monitors workload across team members
- Measures SLA compliance and turnaround time
- Identifies delayed and high-priority requests
- Analyzes returned and reassigned requests
- Compares performance across teams and departments
- Highlights trends that may affect operational efficiency

## Key Metrics

- Total Requests
- Open and Completed Requests
- SLA Compliance Rate
- Average Processing Time
- Average Completion Time
- High-Priority Request Turnaround
- Requests Handled per Team Member
- Return Rate
- Reassignment Rate
- Current Backlog

## Tools Used

- **Power BI** – Dashboard development and visualization
- **DAX** – KPI calculations and performance measures
- **Power Query** – Data cleaning and transformation
- **SQL** – Data preparation and business-rule implementation
